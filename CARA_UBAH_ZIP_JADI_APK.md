# PANDUAN LENGKAP: Cara Mengunduh & Mengubah File .ZIP Menjadi Aplikasi (.APK) di HP (Tanpa Komputer)

Di dalam paket `.ZIP` ini sudah disediakan **2 versi lengkap Julian OmniCore v9.0**:
1. **Source Code Android Native (Kotlin + Jetpack Compose)** — berada di folder `app/`.
2. **Standalone WebApp Siap Konversi APK (`julian_standalone_webapp/index.html` & `manifest.json`)** — khusus buat kamu yang **tidak punya komputer/laptop** dan ingin langsung mengubah file `.zip` / `.html` menjadi aplikasi `.APK` di HP Android!

---

## CARA 1: Langsung Download APK / ZIP dari Menu Google AI Studio di Browser HP
1. Di halaman Google AI Studio tempat kamu chat ini, lihat ke bagian **pojok kanan atas layar**.
2. Ketuk ikon **⚙️ (Settings / Pengaturan)** atau ikon **Download / Export**.
3. Pilih:
   - **"Download APK" / "Generate APK"** untuk langsung mendapatkan file `.apk` siap instal di HP.
   - **"Download ZIP" / "Export to ZIP"** untuk mengunduh seluruh file proyek `.zip` ini ke folder `Download` HP kamu.

---

## CARA 2: Mengubah File `.ZIP` Ini Menjadi `.APK` di HP (Tanpa PC / Tanpa Coding)
Jika kamu sudah mengunduh file `.ZIP` ini di HP kamu, kamu bisa langsung mengubahnya menjadi aplikasi `.APK` menggunakan situs konverter gratis di browser HP (seperti **WebIntoApp.com** atau **AppsGeyser**):

1. Ekstrak file `.ZIP` ini di HP kamu (menggunakan aplikasi File Manager bawaan HP atau ZArchiver).
2. Buka folder **`julian_standalone_webapp`** (atau kompres ulang isi folder `julian_standalone_webapp` yang berisi `index.html` dan `manifest.json` menjadi `.zip`).
3. Buka browser Chrome di HP kamu, lalu kunjungi **[https://www.webintoapp.com](https://www.webintoapp.com)** (gratis & tidak perlu laptop).
4. Pilih tab **"HTML / ZIP File"**, lalu unggah file `index.html` atau `.zip` dari folder `julian_standalone_webapp`.
5. Isi nama aplikasi: **Julian OmniCore**, lalu ketuk **"Make App"** -> **"Download Free APK"**.
6. Setelah file `.apk` selesai diunduh ke HP kamu, buka file tersebut dan ketuk **Instal**!

---

## CARA 3: Menggunakan Aplikasi "HopWeb" atau "Acode" di Play Store (Offline di HP)
1. Instal aplikasi **HopWeb** dari Google Play Store di HP kamu.
2. Buka HopWeb -> pilih **Import Project (.zip / HTML)** -> pilih file `julian_standalone_webapp/index.html`.
3. Ketuk menu **Export / Build APK** di dalam HopWeb untuk langsung menghasilkan file `.apk` di memori HP kamu!
